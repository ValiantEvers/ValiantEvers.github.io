aksje-lab

A value-screening and walk-forward backtesting engine for ASK-eligible equities on the Oslo Stock Exchange and across the Nordics. Built to test whether a factor strategy actually survives costs, tax and honest methodology — not just look good in a spreadsheet. The engine is a private repo; this page summarises the results and how they were reached.

Historical backtest figures, not a forecast. Every headline number is an upper bound: the results carry survivorship bias (only companies still listed are included), so treat them as a ceiling, not an expectation.
Not investment advice. The point is method and reproducibility, not recommending a strategy.

What the tool does

Point-in-time

Same as_of logic for live screening and backtesting. Fundamentals become available on Börsdata's report_Date — true PIT, no lookahead.

Data

Prices from Yahoo, fundamentals + verified ISINs from Börsdata Pro+. ~113 names on Oslo, ~825 across the Nordic universe.

Backtest

Walk-forward out-of-sample segments, cost sensitivity and liquidity-aware slippage — not a single lucky window.

Discipline

312 hermetic tests green, ruff + mypy clean. Pure domain layer with no I/O; all data through one point-in-time port.

Honesty is the point

What sets this apart from a pretty backtest is what the tool refuses to hide.

  • Source-verified or NULL. Identifiers and values come from a verified source or are left blank and flagged — never guessed.
  • Caveat-first. Every report surface carries its caveats openly (survivorship, overfitting, modelled slippage) rather than dressing up the number.
  • Data quality taken seriously. Four independent error classes found and fixed — including an ex-date misalignment and a dividend factor applied up to 3× (caught by cross-validating against Börsdata's dividend calendar). Always via a correction overlay that never mutates source data.
  • Verification gate. A double run is byte-identical; the market series is reconciled against Ødegaard's independent Oslo Stock Exchange data (Pearson 0.976).
  • The real test is coming. A forward paper-log now accumulates survivorship-immune out-of-sample performance over time — the one proof a backtest can never give.

Figures are computed in the tool and taken from a committed report — nothing is computed in your browser, no data is uploaded. aksje-lab is a private repo; this page is a summary.
