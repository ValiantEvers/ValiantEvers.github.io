Prosjekter

  • Aktiv

    Formuessamtalen

    Interaktiv demo av rådgivningssamtalen i wealth management: egnethetskartlegging, åpen allokeringsmatrise, kontovalg mellom depot, ASK og eget AS, og en kalibreringstest bygget på masteroppgaven.

  • Aktiv

    Renteriket

    Spill som lærer bort privatøkonomi fra null, med alle norske satser samlet i én kildeforankret blokk. 1059 automatiserte sjekker dekker matte, oppdrag, lagring og tilgjengelighet; mattesjekkene regner fasiten med andre formler enn spillet bruker, og avdekket blant annet at ett oppdrag var matematisk uløselig.

  • Aktiv

    Personlig Økonomi

    Interaktivt læringsverktøy for personlig økonomi rettet mot vanlige nordmenn. Fem moduler: renters rente-kalkulator med crossover-visualisering, opportunity cost-verktøy basert på streamingkostnader, inflasjonskalkulator med boligprisutvikling, nåverdi, og obligasjonspriser når markedsrenta endres. Bygget med React, Recharts og Framer Motion.

  • Pauset

    OSEBX Dashboard

    Autonomt markedsanalyseverktøy for Oslo Børs. Ukentlig pipeline som analyserer alle ASK-godkjente aksjer (~129) og genererer sektorrotasjon, breddemål og LLM-narrative brief. Bygget med Python og GitHub Actions.

  • Fullført

    GRA6546 – Exam Prep

    Interaktivt eksamensforberedelsesverktøy for GRA6546 Financial Institutions and Crises på BI. Forelesningsnotater, temasider og flashcards organisert per pensumkapittel. Eksamen 13. mai 2026.

  • Fullført

    skatt-mcp

    Lokal MCP-server som lar Claude beregne norsk skatt med faktiske tall framfor generelle forklaringer. Tolv verktøy dekker aksjegevinst (FIFO), verdipapirfond, ASK, formue, bolig, krypto, Nordnet-import og et samlet skatteoppgjør. Kjører 100 % lokalt over stdio – ingen finansdata forlater maskinen. Bygget med TypeScript, MCP-protokollen og Zod. Åpen kildekode (MIT).
